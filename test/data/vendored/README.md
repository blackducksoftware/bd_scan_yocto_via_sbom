## Fixture sanitisation

These fixtures contain only URLs to public open-source code repositories
(`github.com`, `crates.io`, `golang.org`). No credentials, server hostnames,
private paths or Black Duck API tokens are present.

Known-good hosts that appear in fixture content and are expected in step-2 lint:
- `github.com`, `gitlab.com`, `golang.org`, `crates.io`, `static.crates.io`,
  `google.golang.org`, `gopkg.in`, `cloud.google.com`, `honnef.co`
